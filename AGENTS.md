# GameCraft - AGENTS.md

Pure-Rust spatial compiler, scene verification engine, and MCP server for Godot 4.x.

## Repo layout

| Crate | Layer | Role |
|---|---|---|
| `crates/gamecraft-core` | L1 | Node graph, transform hierarchy (`glam`), AABB, collision matrix, signal registry. **No `wgpu`/`egui`/godot deps. Must compile to `wasm32-unknown-unknown`.** |
| `crates/gamecraft-commands` | L1 | `Command` trait (`execute`/`undo`/`serialize_json`) + `AddNodeCommand`, `ReparentNodeCommand`, `SetPropertyCommand`, `SetTransformCommand`, undo/redo `CommandStack`. |
| `crates/gamecraft-godot` | L1 | Deterministic `nom` parser **and serializer** for Godot 4 `.tscn`/`.tres`, deterministic UID hashing, **and the scene lint rules** (`lint.rs`). |
| `crates/gamecraft-mcp` | L2 | Hand-rolled MCP `2024-11-05` stdio server exposing `scene_lint`, `spatial_query`, `export_scene`. Re-exports the lint API from `gamecraft-godot`. |
| `crates/gamecraft-sim` | L1 | Deterministic gameplay sims: kinematic stepper, BFS maze and crate-push solvers. Shared by forge and the MCP verify tool. |
| `crates/gamecraft-forge` | L1 | Depot forge: 13 game builders (platformer/arcade/combat/puzzle), mirrored Rust trace sims, software rasterizer for `thumb.png` / `play.gif`. **Must not depend on `gamecraft-mcp`.** |
| `apps/gamecraft-cli` | L3 | `clap` CLI (`lint`, `query`, `uid`, `forge`). |
| `apps/gamecraft-desktop` | L3 | `egui`/`wgpu` shell: scene tree with lint badges, orbit viewport with AABB/frustum overlays, inspector, live lint, 60-frame trace scrubber, command palette with undo/redo. |

## Depot (`depot/games/<slug>/`)

Fifteen Godot 4.4 projects generated by `cargo run -p gamecraft-cli -- forge --all`.
Each folder is standalone: `project.godot`, `main.tscn`, `scripts/`, `lint.json`,
`trace.json`, `commands.jsonl`, `thumb.png`, `play.gif`, `README.md`.

Three gates per game, all enforced by the forge:

1. `scene_lint` = 0 findings (collision shapes, signal targets, resource ids, camera).
2. Rust trace replay wins inside 600 frames with the same constants the GDScript exports.
3. `godot --headless --path depot/games/<slug> --quit-after 240` prints no ERROR/WARNING.

Plus byte-identical re-export: the forge builds each game twice and refuses a
non-identical scene. Never hand-edit `depot/`; regenerate it.

$env:Path = "$env:USERPROFILE\.cargo\bin;$env:Path"

Plus: `just check-wasm` for the `gamecraft-core` portability probe.

## Rules

- Zero `unsafe`. Workspace lints deny `unwrap_used`, `expect_used`, `panic`, `todo`, `unimplemented` (tests use `assert!` + `if let` / `map_or`, never `unwrap`).
- `clippy::pedantic` is deny: public fns carry `#[must_use]` + `# Errors` docs, no `as` casts, inline format args.
- `gamecraft-core` forbids `wgpu`/`egui`/godot imports so the wasm probe stays green.
- After every mutation: `cargo check --workspace --all-targets`. 3-strike circuit breaker: 3 fails on the same file -> `git checkout -- .` -> emit `[FAIL: CIRCUIT_BREAKER_TRIGGERED]`.
- Stable signatures: do not modify public trait signatures in `gamecraft-core` without updating `gamecraft-commands`, `gamecraft-godot`, `gamecraft-mcp`.
- Godot UIDs (`uid://...`) must be deterministic hash of relative scene path. Never hallucinate `res://` paths.
- Always run `just check` before marking any task complete.
- Kibitzer loop: `KIBITZ.md` is append-only for the kibitzer (never edit entries
  there); builder replies go in `KIBITZ_BACKTALK.md` tail, which the kibitzer LLM
  reads. Check both tails before each phase.

## KV-cache preservation + surgical discovery funnel

- Static preamble: do not re-write system messages or mutate prior turns. Append execution output at tail only.
- Never re-read a file retrieved in last 3 turns. Never request directory dumps. Use targeted search: `rg --files -g '*.rs'`, `rg "symbol"`.
- Funnel before patch: 1. `rg "Symbol"` to locate, 2. `sed -n '50,120p' path/to/file.rs` to inspect range, 3. `ast-grep` for signatures, 4. patch confirmed spans only.
- Dumping full files >200 lines into context is a failure. Slice lines.

## Execution tiers + completion tokens

- PLUMBING (ls, find, rg, git status, read <150 lines): thinking budget 0.
- MUTATION (patches, tests, single-method refactors): budget max 1024 tokens.
- SYNTHESIS (new crates, cross-crate traits, arch failure diagnosis): dynamic up to 8192.
- End every response with one token on its own line: `[STATUS: SUCCESS]` (check+tests green), `[STATUS: PARTIAL]` (compiles, tests unwritten), `[STATUS: FAILED]` (blocked).
