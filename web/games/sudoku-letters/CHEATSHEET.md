# Sudoku Letters: cheat sheet

Same game as Sudoku Classic; the numbers are shown as the letters A to I.

| What | Value |
|---|---|
| Board | 9x9, easy, 51 givens, letters A to I |
| Select | Click a cell |
| Enter | Press the digit keys 1 to 9 (1 = A ... 9 = I); typing a letter does not enter it (A, H and U are the AI, hint and undo keys). Or click a letter button |
| Take back | U or the Undo button, up to 200 steps |
| Hint | H or the Hint button: outlines a cell with one valid candidate |
| AI step | A or the AI button: fills one cell |
| Gate | Headless: the solver fills the grid; checkpoints first-fill, half, solved |
| Win line | GameCraft: tour complete, win |
