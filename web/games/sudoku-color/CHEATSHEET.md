# Sudoku Color: cheat sheet

Same game as Sudoku Classic; the numbers are shown as colours.

| What | Value |
|---|---|
| Board | 9x9, easy, 51 givens, cells tinted by value |
| Select | Click a cell |
| Enter | Press 1 to 9 (the keys are still numbers), or click a coloured button |
| Colours | 1 red, 2 orange, 3 yellow, 4 light green, 5 teal, 6 blue, 7 violet, 8 pink, 9 grey |
| Take back | U or the Undo button, up to 200 steps |
| Hint | H or the Hint button: outlines a cell with one valid candidate |
| AI step | A or the AI button: fills one cell |
| Gate | Headless: the solver fills the grid; checkpoints first-fill, half, solved |
| Win line | GameCraft: tour complete, win |
