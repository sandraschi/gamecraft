# Sudoku Classic: cheat sheet

| What | Value |
|---|---|
| Board | 9x9, easy, 51 givens (given cells are darker and locked) |
| Select | Click a cell |
| Enter | Press 1 to 9, or click the number buttons below the grid |
| Take back | U or the Undo button, up to 200 steps |
| Hint | H or the Hint button: outlines a cell with one valid candidate for 1.5 s |
| AI step | A or the AI button: fills one cell (naked single, else the solution value) |
| HUD | Filled cells out of 81 |
| Done | Solved panel when every cell equals the solution; New puzzle reloads |
| Seed | The seed in the URL fixes the puzzle |
| Gate | Headless: the solver fills the grid; checkpoints first-fill, half, solved |
| Win line | GameCraft: tour complete, win |
