Boomy Sorts

Boomy is a small robot at the end of a conveyor belt. Each parcel stops in front of him, and he sends it into the LEFT bin, the RIGHT bin, or lets it ride ON.

Tell him how with a few rules: IF a parcel is red (and, optionally, big, or has a star) THEN send it somewhere. He reads the rules from the top and follows the first one that fits.

Run the shift and watch. Parcels that end up in the wrong bin get a red flag. Change a rule and run again; the shift is the same each time, so you can compare. Nothing breaks.
