# Boomy Sorts: cheat sheet

| Job | Goal |
|---|---|
| 1 | red left |
| 2 | red left, blue right |
| 3 | big right; small yellow left |
| 4 | big right; star left; green left |
| 5 | small red left; other red right; blue with star left; other big right |

First matching rule wins, so put the exceptions above the general rules.

## Free play (press F)

Boomy holds each parcel at the junction and you push it yourself. Not part of the verified tour.

| Key | Action |
|---|---|
| Left / A | push into the LEFT bin |
| Right / D | push into the RIGHT bin |
| Down / S / Space | let it ride ON |
| 1-5 | pick the job (its goal decides what counts as right) |
| F | back to the rule-writing game |

On-screen LEFT / ride ON / RIGHT buttons do the same on touch. A running tally shows right-of-total and your streak.
