# `gamecraft-cli` (L2 Human & Automation CLI)

Command-line interface for **GameCraft**: environment doctor, game catalog & help cheat sheets, prompt-to-Godot compilation (`new --prompt`), spec compilation (`new --from-spec`), and playback/demo launching.

```powershell
gamecraft-cli doctor
gamecraft-cli list
gamecraft-cli help <slug>
gamecraft-cli new --prompt "a snowy mountain pass at dusk, hard jumps" --provider local
gamecraft-cli new --from-spec depot/games/snowy-mountain-pass/spec.json
```
